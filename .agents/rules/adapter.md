# Codex adapter

Prefix: ADP. `codexbox/codexbox/adapter.py` implements `aicodebox.adapters.base.AgentAdapter` for Codex. The base image loads it through `AICODEBOX_ADAPTER=codexbox.adapter:CodexAdapter`.

- **ADP1:** The base package owns the contract (`RunRequest`, `RunResult`, `StreamEvent`, the method names). Do not change a method signature here to suit Codex. A contract change starts in `psyb0t/docker-aicodebox` and reaches this repository through the published base image.
- **ADP2:** `build_argv` always produces `codex exec`, then `resume <id>` when resuming, then `--json --skip-git-repo-check`, and ends with `-` so the prompt is read from stdin. The prompt never appears in argv (`test_build_argv_prompt_not_in_argv`). `extra_args` go just before the final `-`.
- **ADP3:** Normal runs pass `--dangerously-bypass-approvals-and-sandbox`. `no_tools` runs pass `--sandbox read-only` instead, plus `-c features.shell_tool=false -c web_search=disabled`. Never send both the bypass flag and a sandbox mode.
- **ADP4:** `system_prompt` maps to `-c instructions=...` and `append_system_prompt` to `-c developer_instructions=...`, each as one argv element. `thinking` maps to `-c model_reasoning_effort=...` and must be in `VALID_REASONING_EFFORTS`; `validate` raises `ValueError` otherwise.
- **ADP5:** `tools_allowlist` is logged with a warning and ignored, because Codex has no name-based allowlist of built-in tools. Do not turn it into a rejection: the server modes pass it for every adapter.
- **ADP6:** `json_schema` is written to a temp file and passed with `--output-schema`; Codex only accepts a path.
- **ADP7:** Session continuation: a request with neither `resume` nor `no_continue` resumes the ID pinned for the workspace's resolved path in `$CODEX_HOME/sessions/.codexbox-roots/<sha256>.json`. With no pin, `_latest_rollout_root` takes the newest rollout whose first line is a top-level `exec` session (`source == "exec"`, no `parent_thread_id`, matching `cwd`). The pin is written from `thread.started`, atomically through a temp file and `os.replace`. `no_continue` adds `--ephemeral` and never writes a pin. Never fall back to `codex exec resume --last`; it can pick a subagent rollout.
- **ADP8:** The parsers treat non-JSON stdout lines as expected noise: count, warn and skip, never raise. Only `agent_message` items become text or stream deltas; reasoning and tool items stay out of the answer. `turn.failed` and top-level `error` events set `provider_error`. `input` and `output` usage keys are mirrored to `input_tokens` and `output_tokens`.
- **ADP9:** `auth_paths` returns `$CODEX_HOME/auth.json`, the single credential file for both login modes. `translate_auth` returns nothing, because Codex reads `OPENAI_API_KEY`, `OPENAI_BASE_URL` and `auth.json` itself.
- **ADP10:** A change to the mapping updates `docs/codex-adapter.md`, the `/run` notes in `docs/modes/api.md`, and the skill (agent-surface rules) in the same change.
